What is Software Design Inspection?

A Software Design Inspection is a formal, peer-review process for evaluating software design artifacts (Software Architecture Documents, Database ER Diagrams, REST API specs, UML diagrams) before coding begins. Identifying defects during the design phase reduces rework costs by up to 100x compared to post-release fixes.

Severity vs. Priority Matrix

• Severity: Measures technical or functional impact on the system (Critical, High, Medium, Low, Cosmetic).
• Priority: Measures urgency of correction timeline (Urgent, High, Medium, Low).

How to Resolve & Verify a Defect

  1. Developer: Open My Tasks, click on an assigned defect, and update status to In Progress.
  2. Developer: Modify design document, add developer resolution comment, and update status to Resolved.
  3. Reviewer: Inspect new document version. If fix is verified, set status to Closed.
  4. Reviewer: If fix is incomplete, click Reopen Defect with reason, shifting status to Reopened.
